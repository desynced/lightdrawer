What a receipt does and does not prove

A receipt shows that a file with an exact fingerprint existed no later than the stamped times, and that a file you check later is the same file, byte for byte. It does not show who made or sent a file, that a file is genuine or true, or that anyone agreed to it. It is not a certification, and it does not replace a signature, a lawyer’s advice, or any filing you need. Each guide explains the limits for its own situation.
