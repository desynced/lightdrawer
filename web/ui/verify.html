Check a receipt

See whether a file still matches the receipt made for it, and when that file was recorded.

Your file never leaves this page. This checker is a single file. It works without the internet, and it sends nothing unless you choose an optional online lookup below.

Your receipt The downloaded receipt file (it usually ends in .lightdrawer-receipt.zip)
The original file (recommended) The photo, video, or document the receipt was made for. It is checked here and never uploaded.

What do the results mean?

A match means this exact file existed by the time on the receipt. It does not show who made the file, or that what it shows is true. Any notes in the receipt are the collector’s own words.

If Bitcoin is not confirmed yet, that is normal on a fresh receipt. Confirmation usually finishes within a few hours — tick “Look up the latest confirmations” and try again later.

Technical details

This page checks the receipt’s SHA-256 fingerprint, FreeTSA RFC 3161 token, OpenTimestamps Bitcoin proof, certificate-transparency proof, and optional Sigstore Rekor entry. Built-in Content Credentials (C2PA) are read, not validated.

Trust anchors pinned in this file: FreeTSA root certificate SHA-256 ; Sigstore Rekor public key (rekor.sigstore.dev). Copies inside a receipt are ignored for verification.

A longer, precise walkthrough is in HOW-IT-WORKS on GitHub.
