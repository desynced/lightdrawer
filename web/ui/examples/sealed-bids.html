Example: sealed bids for public contracts

At a bid opening, everyone wants to know the same thing: is this the exact file the bidder sent, unchanged? LightDrawer gives each bid a short trail of fingerprints that anyone can check.

Bids are never uploaded. Only a fingerprint leaves the computer. It is free, and nobody needs an account.

A fingerprint is a short code calculated from a file. Change even one character in the file and the fingerprint changes completely. A LightDrawer receipt records a fingerprint with independent time witnesses, so anyone can check later that a file with that fingerprint existed by that time.

The idea

The same bid file is fingerprinted at three handoffs:

  1. The bidder stamps it before attaching it. This shows that exact file existed by that time.
  2. The agency stamps it on arrival and checks that the fingerprint matches the bidder’s receipt. A mismatch is caught right away, while there is still time to resend.
  3. The agency checks it again at the public opening, after the bid has been in storage. Anyone in the room, or anyone later, can check it too, even offline.

If all three fingerprints match, the file did not change between the bidder and the opening. If one does not match, you know exactly which handoff it changed at.

What this does and does not prove

Please read this part before you put it in a bid notice.

It does show

  • that a file with this exact fingerprint existed no later than each stamped time, and
  • that the file opened at the bid opening is the same file, byte for byte, as the one the bidder stamped and the one the agency received.

It does not show

  • Who sent the file. A receipt says nothing about identity. Keep using your usual way of confirming the bidder, such as a signed bid form, or a digital signature if your rules call for one.
  • That nobody opened the bid early. A fingerprint does not hide or lock a file. Keeping bids sealed until the opening still needs restricted storage, encryption, or a sealed-upload system.
  • That the bid arrived before the deadline. The bidder’s stamp shows the file existed by a certain time, not that it was delivered by then. Email timestamps come from mail servers, not from independent witnesses. The agency’s own arrival stamp adds an independent record that you had the file by then.
  • That anything in the bid is true, complete, or meets your requirements.

LightDrawer is an extra integrity record. It is not a certification, and it does not make a process legally compliant. Check your procurement rules and with your attorney before you require it.

Setting it up: step by step for the agency

Before you advertise

  1. Pick who handles intake. Name one person, and a backup, who receives bids, stamps them on arrival, and keeps the log. If you can, keep this separate from the people who evaluate bids.
  2. Pick where bids are stored until the opening. Use a folder or drive only intake staff can open. Many agencies also keep a second copy on a USB drive, locked up with the paper bids.
  3. Make an arrival log. A simple spreadsheet is enough. Suggested columns: bidder name, file name, time received (from your email or upload system), fingerprint on the bidder’s receipt, fingerprint you got on arrival, match (yes or no), who checked it, and a note.
  4. Add the bidder instructions to the bid notice. Sample wording is below.
  5. Do a practice run. Have a staff member send a test bid through the same email or upload path, then stamp and check it. Some email security systems rewrite or “clean” attachments, which changes the fingerprint. It is much better to find that out before the deadline.

When a bid arrives

  1. Save the attachment exactly as received. Do not open it in an editor, re-save it, print it to PDF, rename the extension, or unzip it first. Just save it to the intake folder.
  2. Stamp it. Drop the saved file onto LightDrawer and download the receipt. The file stays on your computer; only the fingerprint is sent.
  3. Compare fingerprints. The fingerprint is shown on screen. Compare it with the one on the bidder’s receipt, or the one they typed in their email. You can also check the bidder’s receipt directly: open Check a receipt, then drop in their receipt and the file you received.
  4. Log it. Fill in the arrival log row.
  5. If it matches, reply to confirm receipt. You can include the fingerprint you recorded so the bidder can see it matches theirs.
  6. If it does not match, contact the bidder right away. See If something does not match.
  7. Store it. Put the bid file, the bidder’s receipt, and your arrival receipt together in the restricted folder. A simple name works, for example Bid-2027-04 / Acme Paving /.

Before the opening

  1. Copy everything to the opening drive. For each bid, include the bid file, the bidder’s receipt, and your arrival receipt. Also include the arrival log and a copy of the checker page, verify.html. Every receipt also has its own checker inside.
  2. Keep the drive with the sealed bids until the opening.

At the public opening

  1. Check each bid against its receipts. Open verify.html from the drive. It works without the internet. Drop in the bid file and the bidder’s receipt, then the bid file and your arrival receipt. Each one should show a match.
  2. If you like, stamp each file again to add a record of when it was opened.
  3. Read the result aloud for each bid, or show it on screen, and note it in the minutes.
  4. Make the drive, or a copy of it, available to anyone who wants to check for themselves. The checker does not need this website or an account, and nobody has to trust the agency.

If something does not match

A mismatch tells you where the change happened.

Bidder’s receipt vs. arrivalArrival vs. openingWhat it means
MatchMatchThe file did not change.
No match—The file changed in transit, or the bidder stamped a different version. Common causes: the wrong version was attached, the file was zipped or renamed, or an email system altered the attachment.
MatchNo matchThe file changed while the agency had it. Look at storage, copies, and who had access.
  • On arrival: tell the bidder right away and ask them to resend, or to stamp the exact file they are sending. Log every attempt. Do not edit or “fix” the file yourself.
  • At the opening: do not overwrite anything. Set the file aside, record the mismatch in the minutes, and follow your bid-protest or irregularity procedures. Your other copies, such as the email server and the USB backup, and their fingerprints will usually show which copy is the original.

Sample instruction for the bid notice

Edit this to fit your process.

Bid file integrity receipt (requested)

Before you send your bid, make a free integrity receipt for the exact file you will submit:

  1. Finish your bid file. Do not change it after this step.
  2. Go to https://lightdrawer.org and drop the file in. The file stays on your computer; only a fingerprint is recorded. No account is needed.
  3. Download the receipt.
  4. Send the same, unchanged file with your bid. Attach the receipt ZIP too, or paste the fingerprint into your email.

If you send several files, make a receipt for each file exactly as you attach it. If you zip the files, make the receipt for the ZIP.

Do not put prices or other confidential details in the receipt’s optional note. Leave the optional public transparency-log box unchecked.

The agency will make its own receipt when your bid arrives and will tell you right away if the fingerprints do not match, so you can resend before the deadline. The receipt helps show your file was not changed. It does not replace any signature, form, or delivery requirement in this notice.

Good to know

Does the bid stay private?

Yes. Only the fingerprint leaves the computer, and a file cannot be rebuilt from its fingerprint. Keeping bids sealed until the opening is still up to your storage and access rules.

How quickly is a receipt complete?

The timestamp authority’s record is available right away. The Bitcoin and certificate-log records finish over the next few hours. All of them end up in the receipt.

Can we check a fingerprint without LightDrawer?

Yes. The fingerprint is a standard SHA-256 hash. On Windows, run certutil -hashfile bid.pdf SHA256. On Mac or Linux, run shasum -a 256 bid.pdf. The result should match the fingerprint on the receipt.

What if LightDrawer disappears?

Receipts still work. The checker is in every receipt, and the time records live on independent public systems that do not depend on us.
