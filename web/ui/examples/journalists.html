Example: for journalists

You collect a photo, video, document, or disappearing post. Later, an editor asks: is this the file you had then? LightDrawer gives you a dated, checkable record. It is free, needs no account, and never uploads the file.

Your material is never uploaded. Only a fingerprint leaves your device. It is free, and nobody needs an account.

A fingerprint is a short code calculated from a file. Change even one pixel or one character and the fingerprint changes completely. A LightDrawer receipt records that fingerprint with independent time witnesses, so anyone can check later that a file with that exact fingerprint existed by that time.

If you are a photographer documenting your own images, see the example for photographers. This page is about material you collect from others or from the web.

The idea

  1. You stamp each file as soon as you collect it, before anyone opens it in an editor.
  2. You keep the stamped original untouched and work only on copies.
  3. At each handoff (to an editor, a fact-checker, a lawyer, or an archive), the person receiving it checks the file against the receipt.
  4. At publication or later, anyone you choose to show can check it too, even offline.

Matching checks link the copies at those handoffs. A mismatch narrows down where to look; it does not explain what happened.

What this does and does not prove

It does show

  • that a file with this exact fingerprint existed no later than the stamped times, and
  • that the file checked at each later step is the same file, byte for byte, as the one you stamped.

It does not show

  • That the file is genuine. A fake stamped early is still a fake. Verification work is still your job.
  • Who made it or who sent it.
  • That it was not edited before it reached you.
  • That what it shows is true.
  • When or where it was originally created. It shows when you had it.

The optional notes are your own statements, saved with the receipt. LightDrawer does not check them. Built-in Content Credentials (C2PA) are shown if present, but LightDrawer does not check whether they are valid.

LightDrawer is extra evidence of timing and integrity for your records. It is not a certification, and it does not decide whether material is admissible anywhere. Ask your newsroom’s lawyer about what your work may need.

Protecting your sources

Please read this before you stamp sensitive material.

  • Only a fingerprint is sent to the witnesses. The file is not uploaded, and nobody can rebuild it from the fingerprint.
  • The receipt itself is not anonymous. It contains the file’s name, size, and type, the file’s fingerprint, and any notes you add. Anyone you give the receipt to can read all of that.
  • Leave sensitive details out of the notes. Never put a source’s name, contact details, or anything that could identify them in a note. Keep that in your own protected records instead.
  • Rename the file first if its name reveals anything. Renaming does not change the fingerprint, but the receipt records the name you stamped it under.
  • Watch for built-in credentials. If a file carries Content Credentials, the receipt records the device or signer they claim. Think before sharing the receipt.
  • Leave the public log box unchecked. Publishing to the public transparency log is off by default. The entry is public and permanent.
  • Like any website, lightdrawer.org sees your internet connection. LightDrawer’s code does not store your address, but the service that runs the site may keep ordinary request logs. Use your newsroom’s usual precautions.

How to do it, step by step

When you collect a file

  1. Save the original exactly as you got it. Download it from the source or the platform. Do not open it in an editor, crop it, or convert it first.
  2. For a public web page, archive it yourself with perma.cc, the Wayback Machine, or Arweave. You will paste that link into the note.
  3. Stamp it. Go to lightdrawer.org, drop the file in, and open Add a note if you want to record where it came from. The fields are: source URL, archived copy URL, when you collected it, who collected it, how you collected it, and notes. Fill in only what is safe to share.
  4. Check it right away. Open Check a receipt and drop in the receipt and the copy you are keeping. It should match.
  5. Store the original and the receipt together in a restricted folder, with a backup. Work only on copies from now on.

Keep a simple custody log

A spreadsheet is enough. Suggested columns: file name, fingerprint, date collected, who collected it, how, receipt file name, and each handoff (who, when, matched yes or no).

At each handoff

Send the original and its receipt. The person receiving them drops both into Check a receipt and logs the result. If you edit a copy for publication, stamp the edited version too and keep both, so you can show what changed and what did not.

If something does not match

Collected vs. stampedStamped vs. a later checkWhat it means
MatchMatchThe file has not changed since you collected it.
—No matchThe file changed after you stamped it, or this is a different copy. Look at who had it, and at any app that may have converted it.
No match (you stamped a copy)—The copy you stamped was not the original download. Stamp the original now, and note why there are two receipts.

Do not “fix” or overwrite a file that does not match. Set it aside, note it in the log, and compare it with your other copies.

Sample note for the receipt

Downloaded from the public post at the source URL. Archived copy made first. Collected by staff reporter. Platform download; not edited.

Include only what is safe to share.

Sample line for an editor or fact-checker

The original and its LightDrawer receipt are in the shared folder. Please check them at lightdrawer.org/verify.html and log the result before you open a working copy.

Good to know

  • Stamp before you share. Many chat and social apps shrink or convert files. Stamp the original, not a copy that has passed through an app.
  • Timing. The timestamp authority’s record is in your receipt right away. The Bitcoin and certificate-log records finish over the next few hours. When you check the receipt online after that, the checker can fetch the finished records.
  • A second opinion. Any computer can calculate the file’s fingerprint without LightDrawer. On Windows, run certutil -hashfile file.mp4 SHA256. On Mac or Linux, run shasum -a 256 file.mp4. It should match the file fingerprint in the receipt.
  • Lookup link. Each receipt can be looked up at lightdrawer.org/r/ followed by the fingerprint of the receipt’s statement. It is not a backup of your file or receipt.
  • If LightDrawer disappears, your receipts still work. Each one has its own checker, and the time records live on independent public systems.
